## 1. 監査（刷新前の全 60 画面、2026-11-10 撮影）
刷新前の全画面は、非公開リポジトリ Hoku-Tech-ops の `design-handoff/3_全画面.pdf`（198 ページ）にあります。
内訳は PC 1280px の 52 画面と、スマホ 390px の 8 画面です。
レッスン 35 画面と課題 9 画面は同じ部品で作られているため、問題も共通です。

| 重要度 | 画面 | 問題 | 対応 |
|---|---|---|---|
| 高 | 全画面の入力欄 | 入力欄の枠 #dde1e6 が白地に対して約 1.3:1 で、WCAG 1.4.11（3:1）を満たさない | 枠専用の `--border-strong`（3.64:1）を追加 |
| 高 | レッスン 35 画面（PC） | 3 カラムで本文の幅が約 610px。コードの大半が横スクロールになる | 全体の幅を 1152px→1280px に広げ、左右のナビを調整（本文は約 750px） |
| 高 | レッスン 35 画面 | 10 項目が同じ見た目の見出しと本文の連続で、読み分けにくい | 項目ごとに白いカードにし、アイコンと番号を付ける。項目ごとに専用の見せ方を用意 |
| 中 | ホーム | 「次にやること」が淡い青のカードで、他のカードと優先度の差が小さい | 濃い青の大きなカードにし、ボタンを右に置く |
| 中 | カリキュラム | モジュールの区切りと完了状況が文字だけ | L0〜L8 の番号札、モジュールの進捗バー、レッスンの状態アイコン、課題の行の色分け |
| 中 | ヘッダー | ロゴが文字だけ。メニューは下線のタブ | ロゴマーク、アイコン付きのメニュー、選択中は淡い青の地 |
| 中 | ログイン | 中央に入力欄だけで、サービスの紹介がない | PC は紹介（特長 3 つ・飾りの絵）とフォームの 2 列。スマホはフォームが先 |
| 中 | 課題詳細 | ルーブリックの配点「25 点」が折り返す | 配点の列を折り返さない |
| 低 | 全画面 | 地が白一色で、カードの境界が弱い | 画面の地を淡い青灰にし、カードに薄い影を付ける |
| 低 | データが空の表示 | 文字だけの点線の枠 | アイコン付き |
| — | 学習進捗（写真） | 未着手のレッスンが「学習中」と写っている | 撮影のために全レッスンを開いたお試し環境のデータが原因。不具合ではない |

## 2. 画面ごとの変更点（screen change map）
| 画面 | 変更 |
|---|---|
| 共通 | 色の変数、カード・ボタン・入力欄・バッジ・指標カード・進捗バー・空の表示、ヘッダー、ロゴ、ファビコン |
| ログイン | 2 列の配置と、紹介・特長・飾りの絵（HTML と CSS だけで描画）。フォームの項目・動き・文言は同じ |

| カリキュラム | モジュールのカード（番号札・進捗バー・完了の札）、レッスンの状態アイコン・学習目安、課題の行 |
| レッスン（35） | パンくずリスト、見出しカード（L2-3 の札）、10 項目のカード、コードの行番号、実行結果の濃い地、演習・エラーの専用の見せ方、学習完了カード、前後のレッスンのカード、章ナビの状態アイコン、目次カード |
| 課題（一覧・詳細 9） | 共通部品の刷新が反映される。配点の折り返しを修正 |
| 学習進捗・質問とレビュー・マイページ | 共通部品の刷新が反映される |
| 講師・管理者の画面 | 同じ部品を使うため、見た目が一緒に変わる（機能は同じ） |

## 3. 今回は実装しなかったもの（将来案）
ChatGPT の目標イメージにはありましたが、機能の追加になるため外しました。

| 項目 | 理由 |
|---|---|
| 「ログインしたままにする」「パスワードを忘れた方」 | ログインの仕組みの変更になる |
| レッスン内の項目ごとの進み具合（6/10 完了）、目次の項目ごとのチェック | 項目ごとの記録がデータにない |
| 学習のヒント欄、レッスンのタグ | 教材データにない |
| スマホの「レッスン / 練習 / 理解度チェック」タブ、項目ごとに次へ進む方式 | 画面の構成と操作の変更になる |
| 受講生ヘッダーの通知ベル、アバター画像 | 通知は「質問・レビュー」の件数の印で表示中。アバターのデータはない |
| 図解（フローチャートなど）、モジュールのアイコン画像、イラスト | 教材本文と素材画像が必要（ChatGPT からまだ届いていない） |
| ログイン画面の「35 レッスン」などの件数 | ログイン前の画面に DB の情報を出さない方針のため |
