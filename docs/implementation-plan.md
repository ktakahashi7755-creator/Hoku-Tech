## 3. 方針を決めてから着手する項目

* GitHub 連携: 現状は公開リポジトリ URL の提出のみ。OAuth を導入する場合は GitHub App (読み取り専用・リポジトリ単位) とし、
  トークンはサーバー側で暗号化保存して画面・ログに出さない。
* 提出コードの自動実行: 初期段階では実装しない。実装する場合は隔離コンテナ (ネットワーク遮断・CPU/メモリ/時間制限・読み取り専用ファイルシステム) で行う。
* メール送信 (招待・パスワード再設定・通知): 送信サービスの契約が必要 (要承認)。
