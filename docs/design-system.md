# ITS ENGINEER ACADEMY — デザインシステム

> 版: v0.2 (2026-11-06) / 実装: `its-academy/src/app/globals.css`, `its-academy/src/components/ui.tsx`

---

## 1. 方針

* ライトモード標準。白と淡いグレーを基調に、アクセントは落ち着いたブルー 1 色。
* 余白を広く、文字を読みやすく (本文 16px / 行間 1.75)。
* カードは「まとまりを示す必要があるとき」だけ使う。グラデーション・装飾的な影・過剰なアニメーションは使わない。
* `prefers-reduced-motion` ではトランジションを無効化。
* 外部フォント・CDN は使わない (OS の日本語フォント)。

| トークン | 値 | 用途 | コントラスト |

| `--success` / `--success-soft` | `#1c6e41` / `#e8f4ec` | 合格・完了 | 5.5:1 |

すべての文字色は WCAG 2.2 AA (4.5:1) を満たす。色だけで状態を伝えない (バッジには必ず文字を入れる)。

## 3. コンポーネント

| 部品 | 仕様 |
|------|------|
| Button / ButtonLink | 高さ 44px 以上 (タッチ操作)。primary / secondary / danger / ghost |
| Card | tone: default / muted / accent (次にやること) / warning (前回のレビュー) |
| Badge | 状態表示。完了=success、学習中=accent、修正依頼=warning、不合格=danger |
| ProgressBar | `role="progressbar"` と `aria-valuenow` を持つ。数値もテキストで表示 |
| Stat | 指標カード。値がないときは「未評価」 |
| Field | ラベル・補足・エラー (`role="alert"`) をまとめる。入力欄は 44px 以上 |
| CodeBlock / OutputBlock | コード (淡いグレー地) と実行結果 (濃色地) を見た目で区別。コピーボタン付き |
| WeekChart | 7 日分の棒グラフ。各棒の分数を数値でも表示 |

## 4. 学習画面のレイアウト

| 幅 | 構成 |
|----|------|
| 1280px 以上 | 左: 章ナビ (240px) / 中央: 教材 / 右: 目次 (200px) |
| 1024〜1279px | 左: 章ナビ / 中央: 教材 |
| 1023px 以下 | 教材を優先。章ナビは「章の一覧を開く」で折りたたみ |

常に表示: 現在のレッスン名・コース内進捗・学習目安時間・前/次のレッスン・学習完了操作。
教材の各項目は番号付き見出し (01〜10) で区別し、演習は左罫線付きカード、よくあるエラーは赤字のエラーメッセージで区別する。

## 5. アクセシビリティ

* 「本文へスキップ」リンク、`<main id="main">`、ナビは `aria-current="page"`。
* フォームのエラーは `role="alert"`、送信結果は `aria-live` / `role="status"`。
* 表には `scope` 付きの見出しセル。横に長い表は表の中だけを横スクロール (ページ全体は横スクロールしない)。
* フォーカスリングは 2px のアクセント色 (`:focus-visible`)。
* E2E で受講生画面は 375 / 390 / 768 / 1440px、講師・管理者画面は 375px で横スクロールなしを検証。

実施済み: axe-core による WCAG 2.2 A/AA の自動検査 (26 画面で違反 0 件)、キーボードだけでのログインとスキップリンクの確認。
横スクロールする領域 (コード・表) は `ScrollRegion` (role="region"・名前付き・tabIndex=0) で囲み、キーボードでもスクロールできるようにする。
ログイン直後など、フォーカスが失われた画面遷移ではページの見出し (h1) にフォーカスを移す (`FocusOnArrival`)。ページ名は「画面名 | ITS ENGINEER ACADEMY」(レッスン・課題はその名前)。
