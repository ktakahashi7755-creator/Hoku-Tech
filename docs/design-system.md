## 1. 方針

* ライトモード標準です。
  * 画面の地はごく淡い青灰 (`--canvas`) です。その上に白いカード (`--bg`) を置きます。
  * アクセントは落ち着いたブルー 1 色です。緑は「達成・成功」の状態だけに使います。
* 上質さは装飾ではなく、文字の大きさの差・余白・整列で出します。
  * 影は 2 段階 (`--shadow-card` / `--shadow-raised`) だけで、どちらも薄くします。
  * グラデーションは「次にやること」とログイン画面の背景だけに使います。
* 余白は 8px 単位です。角丸は次の 3 段階です。
  * カード: 16px (`rounded-2xl`)
  * ボタン・入力欄: 12px (`rounded-xl`)
  * バッジ: 丸
* 本文は 16px、行間 1.75 です。見出しは 20〜32px で、`tracking-tight` をかけます。
* `prefers-reduced-motion` のときは、トランジションを無効にします。
* 外部フォントと CDN は使いません (OS の日本語フォントを使います)。
* アイコンは `icons.tsx` に自作した線画です (外部のアイコン集は使いません)。
  * すべて飾り (`aria-hidden`) として扱います。意味は必ず隣の文字で伝えます。

| トークン | 値 | 用途 | コントラスト |
|----------|----|------|--------------|
| `--canvas` | `#f7f9fc` | 画面の地 (body) | — |
| `--bg` | `#ffffff` | カード・入力欄・ヘッダー | — |
| `--surface` / `--surface-2` | `#f1f5fa` / `#e8edf4` | 区分けの地・ホバー・バッジ (中立) | — |
| `--border` | `#dce3ed` | 区切り線・カードの縁 (飾り) | — |

| `--text` | `#15233d` | 本文 | 白地 15.7:1 |
| `--muted` | `#526078` | 補足 | 白地 6.4:1 / 画面地 6.0:1 / `--surface-2` 地 5.4:1 |

| `--warning` / `--warning-soft` | `#7a4f00` / `#fdf3e1` | 修正依頼・停滞 | 6.3:1 |

* 色だけで状態を伝えません。バッジやアイコンには、必ず文字か読み上げ用の文字を添えます。
* 「次にやること」は濃い青のグラデーション地に白い文字です (6.9:1 以上)。フォーカスの枠は白にします。

## 3. コンポーネント

| 部品 | 仕様 |
|------|------|
| Button / ButtonLink | 高さ 44px 以上、角丸 12px。種類は primary / secondary (濃い縁) / danger / ghost / inverse (濃い地の上) |
| Card | 白・縁・薄い影・角丸 16px。tone は default / muted / accent / warning |
| CardTitle | 見出しの左に、淡い青の四角に入ったアイコンを付ける |
| PageHeader | 見出しは 28px。任意で上に小見出し (eyebrow)、説明は最大 3xl 幅 |
| Badge | 丸い札で状態を表す。完了=success、学習中=accent、修正依頼=warning、不合格=danger |
| ProgressBar | `role="progressbar"`、数値もテキストで表示。tone は accent / success |
| Stat | 指標カード。アイコン・名前・大きな値・補足。値がないときは「未評価」 |
| EmptyState | 点線の枠・アイコン・文 |
| Field / inputStyles | 入力欄は高さ 48px、縁は `--border-strong`。エラーは `role="alert"` |
| CodeBlock | ファイル名・言語の札・コピーボタン。行番号は見た目だけの列 (`aria-hidden`、コピーに入らない) |
| OutputBlock | 実行結果。濃い地 (`--output-bg`) で、コードと見分ける |

| ヘッダー | 白・ロゴ (マーク + 文字)・アイコン付きメニュー (選択中は淡い青の地)・利用者名・ログアウト。狭い画面ではメニューが 2 行目で横スクロール |

## 4. 学習画面のレイアウト

| 幅 | 構成 |
|----|------|
| 1280px 以上 | 左: 章ナビ (248px) / 中央: 教材 / 右: 目次カード (220px) |
| 1024〜1279px | 左: 章ナビ (260px) / 中央: 教材 |
| 1023px 以下 | 教材を優先。章ナビは「レッスンの一覧を開く」で折りたたみ |

* 上から順に、次のものを置きます。
  1. パンくずリスト
  2. 見出しカード (L2-3 のような番号札、モジュール名と「必修レッスン N / M」、タイトル、学習目安、状態、履修率)
  3. 10 項目のカード
  4. 学習完了カード
  5. 前後のレッスン (前は白いカード、次は青いカード)
* 10 項目は、それぞれ白いカードにします。見出しは「アイコン + 2 桁の番号 + 名前」です。
  * 01 できるようになること: 淡い青のカードに、緑のチェックの箇条書きを並べます。
  * 03 概念の解説: 小見出しの左に青い線を引きます。
  * 06 演習: 左に青い線を引いた枠に「演習 N」と書きます。ヒントと解答例は、開閉できる枠に入れます。
  * 09 よくあるエラー: 赤い帯にエラーの文、その下に原因と対処を並べます。
* 章ナビの印: 完了は緑のチェック、今のレッスンは青い再生マーク、未学習は灰色の丸です。印の意味は読み上げ用の文字でも伝えます。

## 5. アクセシビリティ

* 「本文へスキップ」のリンク、`<main id="main">` を置きます。ナビは `aria-current="page"` で今いる場所を示します。パンくずリストは `nav aria-label="パンくずリスト"` にします。
* フォームのエラーは `role="alert"`、送信結果は `aria-live` / `role="status"` で伝えます。
* 表には `scope` 付きの見出しセルを使います。横に長い表とコードは、その中だけを横スクロールさせます (ページ全体は横スクロールしません)。
* フォーカスリングは 3px のアクセント色です (`:focus-visible`、`outline-offset: 2px`)。
* 画面を移動したときは、見出し (h1) にフォーカスを移します。このとき枠と影は表示しません。
* **2026-11-11 の確認結果:**
  * axe-core (WCAG 2.2 A/AA): 受講生 11 画面 + 講師・管理者 8 画面で、違反 0 件。
  * 横スクロール: 375 / 390 / 430 / 768 / 1024px の受講生画面とログインで、横スクロールなし。
