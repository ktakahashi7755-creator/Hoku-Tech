**ステータス**: 📋中期予定（Phase B完了後）

**想定工数**: 3〜4週間

### 実装内容

| 内容 | 優先度 | リスク |
|------|--------|-------|
| サーバーレスAPIエンドポイント設計 | 高 | アーキテクチャ設計が重要 |
| Claude API (claude-opus-4-6) 接続 | 高 | APIコスト管理が必要 |
| マルチモーダル画像解析 | 高 | 画像サイズ制限に注意 |
| APIキーのサーバー側管理 | 最高 | セキュリティ最優先 |
| トークン使用量・コスト制限 | 高 | 超過防止設計が必要 |

### 技術的な実装方針

```javascript
// Provider Adapterを差し替えるだけで対応可能
window.HOKU_PROVIDER = {
  name: 'claude',
  send: async function(payload, callback) {
    const res = await fetch('/api/hoku', {
      method: 'POST',
      body: JSON.stringify(payload)
    });
    callback((await res.json()).message);
  }
};
```

**完了条件**: 実際のAI応答でマルチモーダル相談が動作すること
