# 画面設計書 — Hoku Tech

---

## S-01 ホーム画面

| 項目 | 内容 |
|------|------|
| 画面目的 | Hoku Techの全体像紹介・学習開始の入口 |
| 利用者 | 受講者・初訪問者 |
| data-view | home |
| 対応関数 | renderHome() |

### 表示項目

- **Hero Section**: ブランド名「Hoku Tech」・メインコピー・サブコピー・CTAボタン
- **統計表示**: Phase数・Lesson数・Skill Check数・面談対策問数
- **12週間ロードマップ**: Phase0-1/2-6/7-9/10-11/12の5段階フロー
- **カリキュラム特徴**: 01〜04の特徴カード
- **Hoku紹介セクション**: Hoku説明・吹き出し・相談チップ・案内ボタン

### スマホ注意事項

- ヒーローコピーは折り返し対応（`<br class="pc-only">`）
- CTAボタンは縦並び
