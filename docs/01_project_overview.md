# Hoku Tech — プロジェクト概要

---

## 1. Hoku Techとは

**Hoku Tech** は、未経験者がAI駆動開発で市場価値の高いフルスタックエンジニアを目指す、12週間の実践型eラーニングカリキュラムです。

React / Next.js、Java / Spring Boot、Python、GitHub、AI活用を体系的に学び、設計・実装・課題提出・ポートフォリオ制作まで一貫して経験します。

**Hoku AIメンター**が学習の相棒として全フェーズに常駐し、エラー相談・コード解説・課題整理・README作成・面談練習をサポートします。ただし、Hokuは人間講師の代替ではなく、最終的な課題レビュー・合格判定・卒業判定は人間講師が行います。

---

## 2. プロジェクト背景

| 課題 | 内容 |
|------|------|
| 未経験エンジニア育成の非効率 | 独学では挫折しやすく、体系的なカリキュラムが必要 |
| AI活用スキルの需要増加 | Claude Code等のAIツールを使えることが採用条件になりつつある |
| SES企業の即戦力不足 | 入場後すぐ動けるフルスタック人材が不足している |
| 24時間サポート体制の難しさ | 講師のリソース制約により、即時対応が困難 |

Hoku Techは、AI（Hokuメンター）と人間講師の役割を明確に分担することで、高品質な学習体験とスケーラブルな運用を両立します。

---

## 3. 目的

- 未経験者がフルスタック開発の基礎から実践まで体系的に習得できる環境を提供する
- AI駆動開発（Claude Code等）を活用しながら、自分の言葉で説明できる開発力を育てる
- SES企業・受託企業への即戦力人材育成を支援する
- 法人向けに再現性のある育成プログラムとして提供する

---

## 4. 対象ユーザー

| ユーザー | 説明 |
|---------|------|
| 一次受講者 | 未経験・転職希望者（PCスキルは最低限あること） |
| 法人・SES企業 | 未経験者採用後の育成プログラムとして活用 |
| スクール・教育機関 | 教材・カリキュラムとして採用 |
| 講師 | 課題レビュー・面談・卒業判定を担う人間教育者 |

---

## 5. 提供価値

### 受講者へ
- 12週間で実践的なフルスタックスキルを習得
- Hokuによる24時間学習支援（エラー相談・コード解説・面談練習）
- ポートフォリオ完成と面談対策

### 法人・SES企業へ
- 再現性のある育成プログラムとしての活用
- AI活用スキルを含む現場対応力の育成
- Hoku利用ログによる学習進捗の可視化

## 8. Hoku AIメンターの位置づけ

```
受講者
  ↓ 相談（エラー・スクショ・コード・課題）
Hoku（AI相棒）
  ↓ 状況整理・考え方提示・テンプレート提供
受講者が自分で考える・実装する
  ↓ 課題提出・Skill Check
人間講師（最終レビュー・合格判定・卒業判定）
```

Hokuは「答えを与えるAI」ではなく、「自分の言葉で説明できる力を育てるAI相棒」として設計されています。

## 9. 技術構成

| 項目 | 内容 |

| 進捗保存 | LocalStorage |
