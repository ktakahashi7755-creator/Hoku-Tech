> このドキュメントは法人・SES企業向け提案の元資料です。

## 1. エグゼクティブサマリー

Hoku Techは、未経験者採用後の即戦力育成を解決する、AI駆動の12週間フルスタックエンジニア育成プログラムです。

- **育成期間**: 12週間（目安）
- **習得技術**: React/Next.js・Java/Spring Boot・Python・GitHub・Claude Code
- **特徴**: Hoku AI 24時間学習支援 × 人間講師による最終評価
- **成果物**: フルスタックアプリ・GitHub公開ポートフォリオ・面談対応力

---

## 2. 未経験者育成の課題

法人・SES企業が未経験者採用・育成で直面する典型的な課題:

| 課題 | 深刻度 | 状況 |
|------|--------|------|
| 独学での挫折率の高さ | 高 | 未経験者の約8割が6ヶ月以内に挫折 |
| 育成コストの増大 | 高 | 講師1人が担当できる未経験者には限界あり |
| 入場後の即戦力不足 | 高 | 現場デビュー後に基礎からの手戻りが発生 |
| AI活用スキルの遅れ | 中高 | Claude Code等を使えないエンジニアの競争力低下 |
| 育成の属人化 | 中 | 担当講師によって品質がばらつく |
| 進捗管理の難しさ | 中 | 個別の詰まりポイントを把握できない |

---

## 3. Hoku Techが解決すること

| 課題 | Hoku Techの解決策 |
|------|-----------------|
| 挫折率 | Hokuが24時間相談受付。詰まっても即時状況整理 |
| 育成コスト | Hokuが初歩質問を担い、講師は評価・深いサポートに集中 |
| 即戦力不足 | 実装・課題・制作まで一貫した実践型カリキュラム |
| AI活用スキル | Claude Code・プロンプト設計をカリキュラムに組み込み |
| 育成の属人化 | 標準化されたカリキュラム・評価基準・Hokuサポート |
| 進捗管理 | LocalStorage進捗・Hoku利用ログで把握（LMS化で強化予定）|

## 5. Hoku AIメンターの価値

### Hokuができること

- エラー相談（エラー文・コード・スクリーンショットから状況整理）
- コード解説（1行ずつの意味・全体の流れ）
- 課題の進め方整理（完成コードの提供はしない）
- README作成支援（必要項目の整理・文章磨き）
- 面談練習（模擬質問・回答整理）
- GitHub提出前チェック（8項目のチェックリスト）
- Claude Code指示文作成補助

### Hokuがしないこと（人間講師が担う）

- 課題の合否判定
- 卒業判定
- AI丸投げの最終判定
- 深い設計相談・アーキテクチャ判断

---

## 6. 講師レビューの価値

Hokuが担えない「評価・判定・深い理解確認」を人間講師が担います。

| 人間講師の役割 | 内容 |
|------------|------|
| 週次面談（30分）| 進捗確認・詰まりポイント解消・モチベーション維持 |
| 課題レビュー | コードレビュー・合否判定（48時間以内）|
| 口頭確認 | 「このコードを説明してください」で理解度を確認 |
| AI丸投げ判定 | 自分の言葉で説明できるか確認 |
| 卒業判定 | 全Phase完了・ポートフォリオ・面談通過 |

## 9. 導入プランイメージ

### プランA: 単独受講（個人）

- 対象: 転職希望・スキルアップ希望の個人
- 内容: 12週間フルプログラム + 週次面談
- サポート: Hoku24時間 + 人間講師週1回

### プランB: 法人一括導入（5名〜）

- 対象: SES企業・IT企業の未経験採用者
- 内容: 12週間フルプログラム + 週次面談
- 追加: 法人向け進捗レポート（月次）・法人担当者との月次ミーティング
- 要問い合わせ: 担当者向けオプション

### プランC: カスタム導入（既存カリキュラム統合）

- 対象: 独自育成プログラムを持つ企業
- 内容: Hoku Techの教材・Hokuをカスタマイズして統合
- 要問い合わせ: カスタマイズ対応
